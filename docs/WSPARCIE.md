# Dobrowolne Wsparcie Autora

Kod i obrazy firmware pozostaja dostepne bez oplaty. Nie dodajemy
blokad funkcji, telemetrii ani obowiazkowego logowania do platnosci.

Publiczny link PayPal zostanie dodany pozniej przez wlasciciela projektu.
Nie wstawiaj do repozytorium hasla PayPal, kluczy API, danych bankowych
ani prywatnego adresu e-mail tylko po to, by utworzyc przycisk.

Gdy masz juz dzialajacy, publiczny link PayPal.Me:

1. Skopiuj `.github/FUNDING.example.yml` do `.github/FUNDING.yml`.
2. Wstaw wlasny prawdziwy adres w `custom:` i usun znak komentarza.
3. Dodaj ten sam adres jako link w sekcji Dobrowolne Wsparcie w README.
4. Sprawdz jako niezalogowany uzytkownik, do kogo prowadzi platnosc.

```yaml
custom: ["https://paypal.me/TWOJA_PUBLICZNA_NAZWA"]
```

To tylko wzor, nie dzialajacy adres. Ustawienia konta, weryfikacje i
obsluge platnosci wykonuje sam wlasciciel na stronie PayPal.

GitHub obsluguje wlasny link finansowania:
[oficjalna instrukcja Sponsor button](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/displaying-a-sponsor-button-in-your-repository).

Okreslenie "dobrowolne wsparcie" nie rozstrzyga kwalifikacji prawnej lub
podatkowej wplat. Nie obiecuj zwolnienia z podatkow; ustal swoje obowiazki
dla wlasnej sytuacji. Projekt nie zbiera ani nie przetwarza wplat sam.
